## Застосовані техніки та розшифровка коду

У проекті реалізовано адаптивну верстку з використанням сучасних підходів CSS3:

1. **Гнучка сітка (Flexbox & Grid):**
   * **Flexbox:** використано для позиціонування елементів шапки, навігаційного меню та кнопок.
     * `style.css` — рядки **24–38** (центрирування та вирівнювання блоків)
   * **CSS Grid:** застосовано для побудови основної сітки товарів та структури футера.
     * `style.css` — рядки **115–130** (автоматична сітка з `repeat` та `1fr`)

2. **Адаптивні медіазапити (Mobile First / Responsive):**
   * Перебудова макета для планшетів та мобільних пристроїв ($<768\text{px}$):
     * `style.css` — рядки **180–245** (зміна напрямку флексів, згортання колонок сітки в один стовпчик)

3. **Сучасні функції CSS та відносні одиниці:**
   * Використання `clamp()` для плавної адаптивної типографіки без засилля медіазапитів:
     * `style.css` — рядки **52–54** (`font-size: clamp(1.5rem, 4vw, 2.5rem);`)
   * Використання відносних одиниць `rem`, `%`, `vw` замість фіксованих пікселів для розмірів та відступів:
     * `style.css` — рядки **10–18**

4. **Інтерактивність та доступність:**
   * Плавні переходи станiв елементів (`transition`) та стилізація фокусу з клавіатури (`:focus-visible`):
     * `style.css` — рядки **70–82**

## Пояснення щодо заміни шрифтів

 При розробці нестандартні шрифти з макета Figma було замінено на безкоштовні аналоги з **Google Fonts** (або системні `sans-serif`), щоб забезпечити швидке завантаження сторінки, коректне відображення кирилиці та кросбраузерність.
